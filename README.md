# MIPS Assembly Linked List Vectors

This project contains a simple MIPS assembly program that reads two vectors, stores them as singly linked lists, and computes their scalar product.

## What it does

- Prompts for the size of each vector
- Reads values for vector 1 and vector 2
- Stores non-zero entries in singly linked lists
- Compares matching positions from both lists
- Computes and prints the scalar product

## File

- `linkedListVectors.asm`

## How to run it

Use a MIPS simulator like MARS:

1. Open the assembly file in the simulator.
2. Assemble the program.
3. Run it.
4. Enter the requested vector sizes and elements.
